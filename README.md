# ComfyHome - Real Estate Platform

ComfyHome is a Django-based real estate platform that enables users to browse, search, and list rental and sales properties. It includes user authentication, custom views for property details, and cost estimation capabilities.

---

## Features

* **Property Listings**: Browse featured listings for rent or sale with detailed specifications (bedrooms, bathrooms, square footage).
* **Search & Filter**: Filter properties by keywords and categories.
* **User Authentication**: Login, customer registration, and dynamic redirect handling (`next` parameter support).
* **Cost Estimation**: Property detail views integrated with geocoding tools.
* **Property Management**: Register properties and manage customer listings.

---

## Tech Stack

* **Backend**: Python 3.14+, Django 6.0+
* **Database**: SQLite (default / development)
* **Frontend**: HTML5, CSS3, JavaScript, Ionicons
