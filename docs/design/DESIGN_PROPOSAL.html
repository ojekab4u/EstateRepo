What stays (your identity)

  • Navy contact strip + coral "Add Listing" — already yours
  • White header, centered nav, square white icon buttons
  • Light hero with eyebrow + left-rule paragraph (homepage untouched)
  • Orange-bordered search strip on the homepage
  • Coral for prices/CTAs, Poppins headings, Nunito body

What changes (and why)

  • Inner pages: default Bootstrap → our navy/coral system (fixes the blue "Apply Filters" clash)
  • Card titles: blue → navy (blue stays for links only)
  • True-cost badge on every card — the product's signature, green/amber/red = verdict colors
  • "Commute km" + amenity score join the feature row
  • Dark navy table headers + sort chips ("Lowest true cost" default)
  • Card titles get hover affordance; buttons rounded 6–8px consistently
⚖️ Why this de-risks homeverse homeverse's README says "free to use" but ships no license file — legally that's "all rights reserved." We keep it only as visual reference for your homepage. The proposed system is an original token set (own colors, spacing, components like the TrueCost badge that homeverse doesn't have), written as our own CSS file — so the product's design is unambiguously yours. Phase 2 replaces homeverse's style.css screen-by-screen with it.
